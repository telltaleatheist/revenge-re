# The pieces of the player's REVENGE.EXE the game takes at start, besides the
# strings named in place by ORIGINAL_TEXT(offset) (every use in src and include
# is a row of its own). tools/import/make_import_table.py reads this list, the
# sources and a copy of an edition (original_editions.txt), and writes that
# edition's src/Support/original_import_table_<ID>.c: offsets, counts, lengths
# and keyed hashes, never the bytes. The offsets are DOS 1.00's.
#
#   header PATH                  included by the generated table
#   KIND NAME DS-OFFSET [COUNT [STRIDE]]
#
# Kinds (include/revenge/original_import.h): text_table, expanded_text_table,
# mutable_text_table, pointed_text, mutable_pointed_text, byte_lists, bytes.
# Offsets and counts are hex. A table's COUNT is its array's; STRIDE is 4
# unless given. A bytes piece's COUNT is its length, which must be the size of
# the object it fills. A mutable pointed text fills its whole char array.
