# The pieces of the player's REVENGE.EXE the game takes. Its texts are each
# a story id: the story file (src/Import) holds them, and the game reads them
# from there; the sources name a single text by STORY_TEXT(ID). The rest is
# data, still taken from the copy at start. tools/import/make_import_table.py
# reads this list and a copy of an edition (original_editions.txt), and writes
# that edition's src/Support/original_import_table_<ID>.c (offsets, counts,
# lengths and keyed hashes, never the bytes), include/revenge/story_text.h
# (the ids and their places) and src/Support/story_text_slots.c (where each
# text goes). The offsets are DOS 1.00's.
#
#   header PATH                  included by the generated tables
#   KIND NAME DS-OFFSET [COUNT [STRIDE]]
#   text ID DS-OFFSET            a single text, STORY_TEXT(ID)
#
# Kinds (include/revenge/original_import.h): text_table, expanded_text_table,
# mutable_text_table, pointed_text, mutable_pointed_text, byte_lists, bytes.
# Offsets and counts are hex. A table's COUNT is its array's; STRIDE is 4
# unless given. A bytes piece's COUNT is its length, which must be the size of
# the object it fills. A mutable pointed text fills its whole char array.
#
# A table's texts are the ids NAME.0, NAME.1 and so on, NAME the table's name
# in lower case with words split by "_" and without "TextTable", "Table" or
# "Text" at its end; a pointed text's id is that name alone. A single text is
# named after the object it fills, or the table and entry it is, or the
# function that uses it in place. One that is an entry of a text_table or a
# pointed_text has that entry's id and no line of its own.
